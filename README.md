Clase                  	Función
d-flex	                Activa Flexbox.
justify-content-between	Distribuye los elementos hacia los extremos.
justify-content-center	Centra horizontalmente.
justify-content-start  	Alinea al inicio.
justify-content-end  	  Alinea al final.
align-items-center	    Centra verticalmente.
align-items-start  	    Alinea arriba.
align-items-end  	      Alinea abajo.
flex-column        	    Organiza verticalmente.
flex-row	              Organiza horizontalmente.
flex-wrap	              Permite que los elementos salten a otra línea.
gap-3	                  Agrega separación entre elementos.
